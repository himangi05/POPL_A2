Prompts for P2: Equations

P2-1 (expression generator)

Follow the prolog-dev skill. In id_q2.pl write expr(Nums, Tree, Value): for a non-empty list of integers Nums it generates, on backtracking, every expression tree over Nums in order. A tree is num(N) or op(Op,L,R) with Op in [+,-,*,/], built by splitting Nums into two non-empty consecutive parts. Value is computed while building the tree (no string parsing). Division is allowed only if the divisor is not zero and the division is exact; this must be checked at every division, not only at the top. Negative intermediate values are allowed. No printing, no libraries beyond lists, apply, yall, aggregate.

P2-2 (canonical printing)

Follow the prolog-dev skill. In id_q2.pl write tree_string(Tree, String) that turns an expression tree (num(N) / op(Op,L,R)) into an SWI-Prolog string, no spaces. Rules: * and / bind tighter than + and -; operators are left-associative; a left operand gets parentheses only if its top operator has lower precedence than its parent; a right operand gets parentheses if its top operator has the same or lower precedence than its parent; a single number never gets parentheses. Examples: (4+2)*3, 4+2*3, 8/4*2 for (8/4)*2, 8/(4*2), 1-2-3 for (1-2)-3, 1-(2-3), 1+(2+3), 1+2+3 for (1+2)+3. The result must be a string, not an atom or code list. Do not parse strings back to terms.

P2-3 (P2.a)

Follow the prolog-dev skill. In id_q2.pl write generate_equation(List, Equation). For some split point j with 1 <= j < length, take every tree for the left part and every tree for the right part (using expr/3) with equal values, and unify Equation with the string "L=R" built with tree_string/2. It must fail (no loop, no error) for lists of length 0 or 1 and when no equation exists. Write only this predicate.

P2-4 (P2.b)

Follow the prolog-dev skill. In id_q2.pl write all_equations(List, Equations): findall of every valid equation string, passed through sort/2 so there are no duplicates and the order is standard order. If there are none, Equations = []. Then write count_equations(List, N) as the length of that list. Write only these two predicates.

P2-5 (tests)

Write tests/p2_tests.pl for id_q2.pl. Include: all_equations([4,2,5,3],Es) must equal exactly ["4*2-5=3","4*2=5+3","4-2=5-3","4/2=5-3","4=2*(5-3)","4=2+(5-3)","4=2+5-3"]; generate_equation([2,3,4],E) fails and all_equations gives []; all_equations([2,4,8],Es) = ["2*4=8"]; plus edge cases: [], [5], [0,0], lists containing 0 (divide by zero must never succeed), inexact division, results are strings, no duplicates, and 1+(2+3) vs 1+2+3 both appearing when valid. Give the command to run it.

P2-6 (review)

Review id_q2.pl against the prolog-dev checklist and the P2 constraints (string output, exact division checked at every division, negative intermediates allowed, no assert/retract, no string-to-term parsing, no output). List problems only, then fix any you find. Also tell me how it performs on lists of length 6 and 7.
