# S2 prompts

## Prompt 1: my-length

Follow the scheme-dev skill. In id_q4.rkt (starts with #lang racket/base, only definitions, only allowed built-ins) write (my-length lst) that counts the top-level elements of a list, tail-recursive. Write only this function.

## Prompt 2: my-map

Follow the scheme-dev skill. Add (my-map f lst) to id_q4.rkt using only allowed built-ins (write your own my-reverse helper if you need one). It must work on a 10,000-element list. Write only this function and any helper it needs.

## Prompt 3: insert-if-short (first version)

Follow the scheme-dev skill. Add (insert-if-short x lst n) to id_q4.rkt using my-length and my-map. It inserts x at the front of every list whose length is less than n, at every level of nesting; the length is the number of top-level elements of the ORIGINAL list; the top-level list is treated like any other; () has length 0 so it becomes (x) when 0 < n; elements are atoms or lists, no dotted pairs. Examples: x=42, lst=((1 2) (3 4 5) (6) ()), n=3 gives ((42 1 2) (3 4 5) (42 6) (42)); x=7, lst=(), n=0 gives (). Write only this function.

## Prompt 4: print-insert-result

Follow the scheme-dev skill. Add (print-insert-result) with no arguments to id_q4.rkt: it reads x, lst, n from standard input, in that order, using read, and prints the result of insert-if-short with display followed by a newline. No prompts or other text. Write only this function.

## Prompt 5: make-inserter

Follow the scheme-dev skill. Add (make-inserter x len-ok?) to id_q4.rkt. It returns a function of one argument (a list) that inserts x at the front of every list, at every level of nesting, whose length satisfies len-ok? (a function taking one number). Length is measured on the original list. Write only this function.


## Prompt 6: insert-if-short defined with make-inserter

Follow the scheme-dev skill. Change id_q4.rkt so insert-if-short is defined using make-inserter, e.g. via (lambda (k) (< k n)). The final file must contain a single definition of insert-if-short, the one that uses make-inserter. Show me the full final file.

## Prompt 7: S2 tests

Write tests for id_q4.rkt in the same style as the S1 tests (a calls file plus a shell script that appends the calls to the code file, feeds stdin and diffs the output). Cover: `42 ((1 2) (3 4 5) (6) ()) 3` gives ((42 1 2) (3 4 5) (42 6) (42)); `0 (((1) 2) (3) ((4 5 6) ())) 3` gives ((0 (0 1) 2) (0 3) (0 (4 5 6) (0))); `7 () 3` gives (7); `7 () 0` gives (); n = 0 with a nested list; a nesting depth of 100; and a list of 10,000 elements. Generate the big inputs with a small script.

Review id_q4.rkt against the scheme-dev checklist: forbidden built-ins, a single definition of insert-if-short, nothing printed on load, the length measured on the original list, and behaviour at depth 100 and with 10,000 elements. List problems only, then fix any you find.
