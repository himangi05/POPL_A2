# P1 prompts

## Prompt 1: candidate/1 generator

```
Follow the prolog-dev skill. In id_q1.pl, write ONLY the predicate candidate(Sol). Sol is a list of four terms p(Name,Dept,Lang,Project) in the order 'Alex','Ben','Carla','Dana'. Dept is a permutation of [research,development,design,testing], Lang a permutation of [python,java,'c++',javascript], Project a permutation of ['AI',web,embedded,data]. Use library(lists) only. No clues, no main, no printing. Add a comment with the declarative reading.
```

## Prompt 2: clues 1 to 4

```
Follow the prolog-dev skill. Add clue/2 clauses for clues 1 to 4 to id_q1.pl. Each is its own clause clue(N, Sol) that succeeds exactly when clue N holds in a fully filled-in Sol (a list of four p(Name,Dept,Lang,Project) terms). Clues: 1. The friend who prefers the AI project does not work in research and is not Dana. 2. Alex does not work in development and does not prefer C++. 3. The friend working in the testing department likes Python. 4. Ben prefers web projects and does not work in testing. Put a comment with the clue text above each clause. Do not write anything else.
```

## Prompt 3: clues 5 to 8

```
Follow the prolog-dev skill. Add clue/2 clauses for clues 5 to 8 to id_q1.pl, same style as clues 1 to 4. Clues: 5. The friend whose favorite language is Java works in the design department. 6. Carla's project preference is not embedded, and her department is not development. 7. Dana's favorite language is not Java, and she works in research or testing. 8. The friend who prefers data projects works in research and does not use JavaScript. Comment with the clue text above each clause. Do not write anything else.
```

## Prompt 4: satisfies/2

```
Follow the prolog-dev skill. Add satisfies(Active, Sol) to id_q1.pl: it succeeds when clue(N, Sol) holds for every N in the list Active. Write only this predicate.
```

## Prompt 5: main/0

```
Follow the prolog-dev skill. Add main/0 to id_q1.pl. It finds ONE Sol with candidate/1 and satisfies/2 using clues 1 to 8 (derive it from the clues, no hard-coding), and prints exactly four lines in the order Alex, Ben, Carla, Dana, in the format `Alex = [Dept, Lang, Project]` (e.g. `Carla = [design, c++, embedded]`). Atoms must print unquoted. Print nothing else, no halt/0.
```

Follow the prolog-dev skill. Add count_solutions(Active, N) to id_q1.pl. Active is a list of clue numbers; N is the number of solutions satisfying exactly those clues and ignoring the others. Use findall/3. Write only this predicate.
