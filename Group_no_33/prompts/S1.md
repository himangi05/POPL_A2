# S1 prompts

## Prompt 1: inorder-list

Follow the scheme-dev skill. In 33_q3.rkt (starts with #lang racket/base, only definitions, only the allowed built-ins) write (inorder-list tree) that returns the list of values of a binary tree in inorder. A tree is () or (value left right). Do not use append or reverse. Write only this function.

## Prompt 2: print-inorder

Follow the scheme-dev skill. Add (print-inorder tree) to id_q3.rkt: prints with display the inorder list on one line, ending with a newline. For '() it prints (). Write only this function.


## Prompt 3: preorder-list

Follow the scheme-dev skill. Add (preorder-list tree) to id_q3.rkt that returns the values in preorder (node, left, right). No append or reverse. Write only this function.


## Prompt 4: postorder-list

Follow the scheme-dev skill. Add (postorder-list tree) to id_q3.rkt that returns the values in postorder (left, right, node). No append or reverse. Write only this function.


## Prompt 5: print-all-traversals

Follow the scheme-dev skill. Add (print-all-traversals tree) to id_q3.rkt: prints three lines with display, in order inorder, preorder, postorder, each ending with a newline. Use the existing helper functions. Write only this function.


## Prompt 6: tree-height

Follow the scheme-dev skill. Add (tree-height tree) to id_q3.rkt: height of () is 0, a node's height is 1 plus the larger of its subtree heights. Use only max and the allowed built-ins. Write only this function.


## Prompt 7: leaf-count


Follow the scheme-dev skill. Add (leaf-count tree) to id_q3.rkt: a leaf is a node whose left and right subtrees are both (); the empty tree has 0 leaves. Write only this function.



## Prompt 8: print-height-and-leaves


Follow the scheme-dev skill. Add (print-height-and-leaves tree) to id_q3.rkt: prints the list (height leaf-count) on one line with display, followed by a newline. For '() it prints (0 0). Write only this function.



## Prompt 9: S1 tests

Cover the examples from the assignment: t1 (4 (2 (1 () ()) (3 () ())) (6 (5 () ()) (7 () ()))) gives (1 2 3 4 5 6 7) / (4 2 1 3 6 5 7) / (1 3 2 5 7 6 4) and (3 4); t2 (1 () (2 () (3 () ()))) gives (1 2 3), (1 2 3), (3 2 1) and (3 1); t3 (a (b () ()) (c () ())) gives (b a c), (a b c), (b c a) and (2 2); and '() gives () three times and (0 0). Also a single-node tree and a deep 1000-node left-leaning tree.
